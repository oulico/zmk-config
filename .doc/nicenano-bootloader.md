## UF2 부트로더 진입 방법

### 방법 1: 리셋 버튼 더블탭 (정상)
리셋 버튼을 빠르게 두 번 누른다.
- 1회 탭 → 펌웨어 재시작 (부트로더 아님)
- **2회 탭 (1초 안에)** → UF2 부트로더 진입

### 방법 2: RST 패드 직접 쇼트 (납땜 불량 시)
리셋 버튼 납땜이 떨어진 경우, PCB의 RST 패드와 GND 패드를 트위저나 철사로 **빠르게 두 번** 단락한다.

```
RST ─── GND  (짧게 접촉, 0.3초 이내)
RST ─── GND  (다시 짧게 접촉, 1초 안에)
→ 부트로더 진입
```

## LED 상태 해석

| LED 상태 | 의미 |
|----------|------|
| 꺼짐 또는 호흡 | 정상 동작 중 |
| **계속 켜짐 (solid on)** | **UF2 부트로더 모드** ← 합선 아님! |
| 빠른 점멸 | 오류 또는 페어링 중 |

**LED가 계속 켜져 있으면 부트로더 진입 성공이다.** Finder에서 `NICENANO` 또는 `NRF52BOOT` 드라이브가 마운트됐는지 확인한다.

## 펌웨어 플래시

부트로더 진입 후 드라이브가 마운트되면 `.uf2` 파일을 드래그 앤 드롭한다. 자동으로 재시작되며 LED가 꺼진다.

## ZMK 분리형 키보드에서 좌우 개별 플래시

- **왼쪽 (Central)**: 키맵, HRM 타이밍, 모든 behavior 저장. 키맵 변경 시 반드시 플래시해야 함.
- **오른쪽 (Peripheral)**: 매트릭스 스캔 결과만 왼쪽으로 전송. 오른쪽만 플래시해도 키맵 동작은 바뀌지 않음.

한쪽만 부트로더 진입이 안 되면 그쪽 펌웨어 변경사항은 적용되지 않는다.
